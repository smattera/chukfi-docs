## Rust Native, Source-First

Chukfi ships as a Rust binary via `cargo install chukfi-bin`. Clone the repo for the full stack — Dioxus admin UI, config templates, and Docker Compose setup.

```bash
cargo install chukfi-bin
chukfi serve
```

## Chat to Publish

Connect Chukfi to Microsoft Teams. AWS Bedrock running Claude drafts posts, rewrites copy, and generates metadata — all from a chat thread. Every AI change is forced to **draft**. Human approval is hardcoded.

## Deploy Anywhere

Build from source for local dev with Docker Compose, push to AWS ECS Fargate + RDS for production, or deploy your frontend to Cloudflare Pages with one command.

```bash
chukfi site deploy --dir ./frontend --project my-site
```
